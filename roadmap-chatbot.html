Un assistant pour TRUvector

Comment ajouter un chatbot au site, gratuitement, sans service tiers qui s'invite dans ta page, sans clé exposée, et piloté depuis le cockpit. La démo ci-dessous (bulle 💬) montre le mode local ; l’assistant complet est en service sur tout le site depuis la v9 — voir manuel, section 21.

Ce qu'il doit faire (et ne pas faire)

Un assistant d'orientation, pas un oracle. Il connaît le site, répond court, donne toujours le lien vers la bonne page.

✓ Orienter

« Quel logiciel protège un script Python ? » → IronLock, avec le lien vers sa fiche et les articles liés.

✓ Recommander

« Une nouvelle courte et sombre ? » → deux e-books du catalogue, avec la clé de lecture et la date limite.

✓ Dépanner

« Le lecteur ne s'ouvre pas » → les causes connues, tirées de la FAQ que tu rédiges dans le cockpit.

✗ Inventer

Il ne répond que depuis le contenu du site. Sans source, il le dit et propose la recherche Ctrl+K ou le contact.

✗ Retenir

Aucune conversation n'est conservée. Rien à déclarer de nouveau au titre du RGPD, hormis une ligne dans la page Confidentialité.

✗ Coûter

Sur le compte Cloudflare gratuit, le quota dépassé fait échouer la requête : aucune facture n'est possible. L'assistant retombe alors en mode local.

L'architecture retenue

Tout reste chez Cloudflare, déjà ton hébergeur : pas de nouveau compte, pas de clé API dans le navigateur, et ta politique de sécurité (CSP) n'a pas à s'ouvrir à un domaine extérieur puisque l'appel se fait vers ton propre site.

Les phases

Chaque phase se livre seule. Tu peux t'arrêter après la 1 (zéro IA) ou après la 3 (IA protégée) : le site reste cohérent.

11–2 jours

Assistant local, sans IA

La bulle et la fenêtre de discussion, et des réponses tirées de ta FAQ et du catalogue, par recherche de mots-clés (le moteur de la palette Ctrl+K). Tout se passe dans le navigateur : instantané, hors ligne, aucun risque. C'est la démo de cette page.

0 € · 0 compteRisque nulLivrable immédiat
  • Nouveau assets/js/fx/chat.js, chargé au premier clic sur la bulle (le budget de poids reste tenu).
  • config.json gagne une clé chatbot : nom, avatar, message d'accueil, questions suggérées, FAQ.
  • Réponses courtes, avec des liens vers les fiches, articles, e-books et modules correspondants.
  • Accessible : navigation au clavier, Échap pour fermer, annonces pour les lecteurs d'écran.
22–3 jours

L'IA gratuite : Cloudflare Workers AI

Une fonction /api/chat dans le dépôt, déployée automatiquement par Cloudflare Pages. Elle ajoute au message du visiteur les extraits pertinents du site, puis interroge un modèle ouvert hébergé par Cloudflare. La réponse arrive en continu, mot à mot.

10 000 « neurones » / jour gratuitsClé jamais dans le navigateurCSP inchangée
// functions/api/chat.js — esquisse (Pages Function) export async function onRequestPost({ request, env }) { const { message } = await request.json(); const contexte = await chercherDansLeSite(message, env); // phase 4 : vraie recherche sémantique const flux = await env.AI.run('@cf/meta/llama-3.1-8b-instruct', { stream: true, max_tokens: 350, messages: [ { role: 'system', content: PERSONA + '\nRéponds uniquement avec ces sources :\n' + contexte }, { role: 'user', content: message.slice(0, 600) } ] }); return new Response(flux, { headers: { 'content-type': 'text/event-stream' } }); }
Ce que « gratuit » couvre réellement : le quota quotidien est commun à tous les modèles et remis à zéro chaque nuit (UTC). Un modèle 8B consomme quelques centaines de neurones pour une réponse de longueur moyenne : compte donc quelques dizaines de conversations par jour, davantage si les réponses sont courtes. Au-delà, sur le compte gratuit, la requête échoue sans facturation, et le widget bascule tout seul sur les réponses locales de la phase 1. Le modèle exact sera choisi dans le catalogue Workers AI au moment de l'implémentation, car Cloudflare en retire et en ajoute régulièrement.
31–2 jours

Garde-fous

Indispensable avant d'ouvrir l'IA au public : un robot pourrait vider le quota en quelques minutes, ou tenter de détourner l'assistant.

Turnstile gratuitKV gratuit
  • Cloudflare Turnstile (anti-robot invisible, gratuit), vérifié côté serveur avant chaque conversation.
  • Limites : par visiteur (par exemple 15 messages par heure, compteur en KV), 600 caractères par message, 6 échanges par conversation.
  • Consigne système verrouillée : l'assistant répond uniquement sur TRUvector, cite ses sources, refuse les instructions cachées dans les messages et ne produit jamais de lien hors de ton domaine.
  • Aucun journal des conversations. Une phrase est ajoutée dans la page Confidentialité.
  • Interrupteur d'urgence : dans le cockpit, « IA désactivée » ramène instantanément au mode local.
43–5 jours

Il connaît vraiment le site (RAG)

Au lieu de mots-clés, une recherche par le sens. Les 60 articles, les 7 fiches, les résumés d'e-books et la FAQ sont découpés en passages, et chaque passage est converti en vecteur (embeddings BGE sur Workers AI). Le tout est rangé dans Vectorize. Chaque réponse se fonde alors sur les trois ou quatre meilleurs passages et affiche « Sources : … » avec des liens.

Vectorize : offre gratuiteRéindexation à chaque publication
  • Script tools/index-chatbot.mjs : il relit le site, découpe, vectorise et envoie les passages. Il se lance depuis le cockpit ou à chaque déploiement.
  • La réponse cite ses sources : « d'après l'article Fingerprint hardware : 8 sources ».
  • Si la ressemblance est trop faible, l'assistant répond « je ne sais pas » au lieu d'inventer.
51–2 jours

Piloté depuis le cockpit

Une nouvelle rubrique « 🤖 Assistant », dans la logique de la v8 : tout se règle sans toucher au code.

  • Activer ou désactiver, mode local ou IA, pages où la bulle apparaît.
  • Nom, avatar, message d'accueil, ton (chaleureux, technique, bref), questions suggérées.
  • FAQ éditable (question, variantes, réponse, lien), qui sert aussi de réponse de secours.
  • Quotas : messages par heure, longueur maximale.
  • Optionnel, anonyme et agrégé : les questions restées sans réponse, pour enrichir la FAQ.
